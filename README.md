Master's Thesis Project: Proactive Conversational Agents
This repository contains the full codebase for my Master's Thesis, focused on researching and developing proactive natural language models and their impact on social interaction.

🚀 Overview
The goal of this project is to transform traditional AI agents from reactive (responding only when prompted) to proactive entities that can initiate and guide conversations based on specific research parameters.

📁 Project Structure
The project is organized into three main components:

/Lexi: The central management dashboard and server.

Note: This component is based on the original Lexi project by Tomer lavan - https://github.com/Tomer-Lavan/Lexi. It has been extended and modified to support proactive settings, experiment management, and real-time interaction monitoring.

/android-app: A specialized mobile application designed for experiment participants, supporting proactive notifications and real-time LLM interactions.

/logic-python: (Optional: add a brief description of what this folder does, e.g., data analysis or specific LLM scripts).

🛠 Features Added in this Research
Proactive Experiment Control: A dedicated UI to toggle proactivity and adjust message frequency per experiment.

Dynamic WorkManager Integration: Android-side logic to handle background proactive triggers.

Real-time Synchronization: Full-stack integration between the management dashboard (MongoDB) and the mobile end-point.
